# 转交前选择（beta.5）

真实额度触发原有阈值且有未完成的已授权任务时，GPT先调用handoff_confirm。Windows独立置顶窗口显示任务名称与“立即转交/暂不转交”，并说明30秒未回答会自动开始。它属于本工具的桌面界面，不走MCP审批询问，不修改never或其他审批、安全设置。点击立即转交会立即放行；点击暂不转交或关闭窗口后本次不会打包、建立Harness聊天或派发。

30秒由桌面窗口计时，只计入窗口已显示且当前登录会话的普通桌面可交互的时间。窗口显示前、锁屏、UAC安全桌面、远程会话断开或明显计时中断时不默许；窗口无法可靠显示或55秒仍未取得有效响应时返回不可用，不冒充用户拒绝。等待期间不运行模型、不创建系统定时。超时放行只授权继续当前任务的现有打包转交流程，不扩大文件范围、修改阈值或表示任务已完成。

确认按原对话和稳定任务编号持久记录；并发调用不会重复询问，重启后的未知等待记录也不会仅凭时间自动放行。拒绝不会因下一张额度票据再次弹窗。用户明确说重新选择时可reconsider=true重新询问；真实额度恢复后再次触发阈值也会重新询问。

询问通道不支持、连接出错或原轮次中断时保留进度，不将故障当作用户未回答。取消属于拒绝。确认通过后仍须检查新鲜额度、任务状态、文件授权及幂等执行记录。

窗口在当前Windows登录桌面独立显示，有任务栏入口、置顶和提示音；切换对话、停留GPT首页或最小化GPT不会按当前选中的聊天隐藏它。GPT及其后台必须仍运行，且原任务仍有触发额度检查的执行活动；完全退出程序、未登录、锁屏、UAC安全桌面和独占全屏/其他置顶覆盖不能承诺可见，不尝试修改系统防护。普通置顶窗口的能力边界见[微软说明](https://learn.microsoft.com/en-us/dotnet/api/system.windows.window.topmost)。

beta.4的MCP表单可能在never模式下由宿主立即取消，不能证明用户拒绝。beta.5不再用该通道作为默认；旧版无可见性证据的拒绝记录在重新询问时归档保留，不静默改成批准。新记录保存displayedAt、visibleMs及windows-desktop来源。

部署后需正常重载GPT工具；capabilities报告beta.5及protocol=windows-desktop，visibilityVerified=false表示能力声明不替代本次实际显示证据。脚本执行受本机现有PowerShell策略约束，禁止使用ExecutionPolicy Bypass。策略不允许、缺少交互桌面等情况须明确报告。
