# 分享边界

运行npm run verify:release生成release/staging白名单目录和SHA256清单。分享该目录或其压缩包；不要压缩正在使用的整个开发目录。

发行内容：源码、编译产物、通用插件、Skill、配置规范、工具脚本、通用测试、脱敏示例、说明及第三方依赖许可文本。

绝不包含：.local、用户项目、任务账本、聊天/调度ID、执行快照、备份、账号配置、密钥、钩子信任记录、安装清单/设置备份、原作者诊断日志、依赖目录或旧工程参考。运行记录即使不是密码也不应默认外发。

接收者各自安装依赖、使用正常登录、选择授权来源目录并生成新配置。无需复制原作者账号或设置，也不连接新计费API。不要宣传为官方产品或支持任意宿主。

本工程尚未选择标准开源许可证。当前作为项目拥有者定向共享的预览工程交付，公开发布或商业分发前需由项目拥有者确定项目许可；第三方依赖仍分别适用其自身许可，见THIRD-PARTY-LICENSES.txt。不将第三方软件重新声明为本项目所有。
