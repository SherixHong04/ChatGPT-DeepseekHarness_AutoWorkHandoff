# Work Handoff 0.3.0-beta.8

2026-10-25发布的Windows共享预览版。本版将beta.4至beta.8的转交询问、兼容修复和界面改进合并到主分支；版本继续保留beta标记。

## 更新内容

- Harness续聊参数改为新版支持的queue，修复旧followup不兼容。
- 双窗口最小剩余额度严格低于20%且存在未完成的已授权任务时，先询问是否转交；恰好20%继续工作。工作/交接/验收预留为5/5/10，交接准入至少15%、验收至少10%、恢复暂停任务至少40%。动态预测尚未启用。
- 默认使用独立Windows置顶窗口和任务栏入口；切换GPT对话或最小化GPT不会按当前聊天隐藏窗口。GPT后台及额度检查活动仍需运行。
- 修复MCP表单被宿主自动取消却混同用户拒绝的问题；修复交互窗口继承隐藏启动状态的问题。原生可见性、最小化、虚拟桌面隐藏与中心遮挡检查控制倒计时。
- 30秒仅累计窗口已显示且桌面可交互的时间；拒绝、关闭、Esc、连接故障或无法显示时不默许转交。拒绝按任务与原对话保留，不因新额度票据反复询问。
- 新界面宽420逻辑像素、普通高约240，支持显示器DPI、浅深色、长任务名与可视倒计时。

## 升级

1. 保存当前工作，按原安装说明更新程序文件及Harness插件；保留个人配置、数据库、运行副本和备份，不用发行目录覆盖整个运行目录。
2. 要采用20%门槛，将本机工具配置中的quotaPolicy.workPercent设为5，handoffPercent=5、reviewPercent=10、resumePercent=40。全新安装默认采用这些值；已有个人配置不会自动覆盖。
3. 正常重载Harness插件和GPT工具。调用handoff_capabilities核验version=0.3.0-beta.8、handoffConfirmation.protocol=windows-desktop；能力声明不替代实际窗口可见性证据。

不需要管理员权限，不修改审批、安全设置或PowerShell执行策略。遇到本机策略阻止或缺少交互桌面时应保留现场并报告原因。

## 验证及边界

178项本地测试及13项隔离安装检查通过，包含20%精确边界、双窗口约束、确认前禁止打包和派发、拒绝及故障不放行。用户已实际确认修补窗口可见并点击拒绝、切换应用/最小化后仍可见，以及新版大小和清晰度改善；实际可见倒计时约30秒后返回超时。浅深色、长任务名及96/144/192 DPI渲染检查通过，本机实际窗口DPI为144。检查未创建真实模型任务或聊天。

这些证据不等于跨电脑、实际额度耗尽恢复、新客户端完整模型交接、多轮取回写回归档全部验证通过。完全退出GPT、锁屏、UAC安全桌面、非交互会话和独占全屏/其他置顶窗口遮挡仍有边界，不能承诺在所有桌面状态下显示或计时。

发行包采用白名单和文件哈希清单，排除个人配置、账本、账号、聊天、运行副本、依赖目录和备份。安装方式及完整证据参见INSTALL.md、HANDOFF-CONFIRMATION.md及verification/RESULTS.md。
