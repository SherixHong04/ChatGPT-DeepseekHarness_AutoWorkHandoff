# 验证范围

本次交付在同一Windows电脑的新D盘工程中进行，本地无模型验证包括：干净依赖安装、严格类型构建、原有用例回归、正式同聊天工具派发/收取/未知不重发/用户续聊/旧验收失效/写回保护、隔离目录安装卸载、MCP标准连接，以及发行扫描。

新电脑、新用户自己的账号、原生钩子信任、实际Harness宿主版本、真实额度耗尽恢复、真实定时接回与人工续聊仍需接收者正常任务验证。本地fixture返回“accepted”不冒充真实模型接收证据。安装包本身不会自动替换已有安装、任务或调度，用户需执行正常安装或明确迁移。

0.3.0-beta.2增加全局监测和任务资料自动定位，覆盖多个工程、无工程摘要、附件、同名选择、任务归属和跨进程MCP连接。测试使用隔离目录及合成对话身份，不能称为在两个真实GPT聊天中实测原生钩子；真实链路须使用该用户实际原对话的get_usage_limits及自动完成钩子票据核对。没有默认新增真实测试聊天、模型任务或定时。

原工程已有正常桌面同聊天执行与原对话接回实测作为设计依据，但原作者原始记录未随包分发；它不是本共享版在另一电脑通过的证据。测试统计和结果见verification/RESULTS.md。

稳定发行前待补：跨电脑现场验证、两端实际升级验证、真实人工多轮并发窗口测试、对外项目许可证选择。当前Windows预览版不承诺macOS/Linux或普通ChatGPT网页/手机可用。
